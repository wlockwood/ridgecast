# Sidebar workbench

Approved direction: option 2 from the sidebar mockups, with a pinnable Layers drawer.

Keep site selection and inspection in a persistent left Network panel. Keep coverage assumptions, calculation controls, and results in a separate right Coverage panel. Put cartographic appearance and data preparation in a labeled Layers drawer on the map. Floating and pinned presentations use the same settings and remember their state.

Preserve existing calculations, cached node ordering/link summaries, context menus, background downloads, overlays, and serialized configuration compatibility. Empty selection must continue to clear coverage; disabled, hidden, and marker nodes must not inflate the coverage selection count. Unique coverage compares one selected network radio against the network.

Coverage exposes direction, test-radio assumptions, the coverage question, sampling presets, default range, workload estimate, and results. Exact resolution, algorithm, and network-wide range reset belong in Calculation options. Coverage styling belongs in Layers. Terrain source configuration stays in Terrain & Geodata Settings, reachable even when the overlay is hidden. Fit commands belong on the map.

Both planning panels and the drawer scroll independently. All new controls have tooltips. Document the new navigation and verify old map settings files still load.
