# Use the in-app guides

Press **Guide** in a workspace panel or tool to open help beside it. The guide
explains the task, the order of the controls, and limits that matter when
interpreting the result. **Open full documentation**, or the named documentation
link in the original guides, opens the relevant bundled page.

Guides are nonmodal: you can keep working with the tool while reading. Move or
resize a guide if needed; its body scrolls on smaller displays. **Close**, the
window's **X**, and **Dismiss guide** dismiss help without canceling the tool's
work. **Escape** dismisses a guide when it has focus. Closing its owner also
closes the guide; collapsing a tool's contents hides its companion help.

New tool guides open only when requested. Each guide has an independent
**Show guide when this tool opens** preference, saved across restarts. Enabling
it opens help on subsequent openings of that tool. Turning it off leaves the
**Guide** button available. For the persistent Network and Coverage panels,
an opening means application startup. The original Main Viewport, Node Editor,
Site Finder and Link Profile guides retain their existing saved preferences.

Guide buttons are available in these places:

| Workspace or tool | What the guide covers |
| --- | --- |
| Main map toolbar | Navigation, selection, movement, provisional links and ruler |
| Network | Site selection, editing and directional viable links |
| Coverage | Test radio, TX/RX/two-way, coverage questions, radius and sampling |
| Layers, floating or pinned | Display versus calculation inputs, data preparation and docking |
| Single and Bulk Node Editors | Profile inheritance, overrides, height references and undo |
| Radio Systems Manager | Shared equipment defaults and their effect on sites |
| Link Profile | Directional budgets, clearance, data sources and height proposals |
| Site Finder | Candidate area, scoring, radio baseline, compute modes and shortlist validation |
| Analysis Results | Network snapshots, assumptions, freshness and result limitations |
| Propose Repeater Chain | Candidate constraints, both-direction margins and reviewing a proposal |
| Transmitter Height Impact | Two-height comparison, GIF steps and TX coverage assumptions |
| Performance & Calibration | Workload choices, competing jobs and calibration scope |
| Terrain & Geodata Settings | Terrain sources, LiDAR scopes and extraction settings, resolution, caches and recalculation |
| Land Cover Settings | Categorical clutter assumptions and missing data |
| Local Terrain and Surface Sources | DEM, paired DSM/DTM and WorldCover import requirements |
| FCC Amateur Licenses | Catalog filters, shared locations and hypothetical equipment |
| Node Sources | Trusted feeds, import review and validation |
| Prepare Offline Area | Geographic bounds, file availability and preparation |
| Offline task readiness | Task-specific sampled availability and bounded preparation |
| Downloads | Dataset status, failures and offline verification |
| Tile Manager | Overlapping source layers, tile selection and cache deletion |
| Export Coverage Image | Viewport, presentation, resolution and reviewing output |
| Export GIS Data | Formats, scope, units and validation in another GIS |
| Application Preferences | Units, application settings and save feedback |
| Fade Margin Settings | Visible-link cutoff, color bands and serving-site threshold |
| Link View Settings | Selecting a link view, per-view filters and palettes, Fortuity defaults, recursive connectivity, and interpreting color examples |
| Ambient Noise Settings | Receiver references, measurements and directional differences |
| Bulk Add Nodes by Coordinates | Patterns, preview validation and creating sites |
| Ruler Terrain Profile | Route editing, terrain and the difference from a radio path |

Small single-purpose dialogs such as Network Frequency and Coverage Owner
Colors use tooltips and inline explanations. Progress, result messages and
confirmation dialogs keep their explanations in the dialog itself.
